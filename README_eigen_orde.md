# HMS Harmful Brain Activity Classification

## Project
Machine learning project for Kaggle HMS Harmful Brain Activity Classification competition.

## Baseline
Original models:
- Logistic Regression
- HistGradientBoosting

## Experiments ideas 
- KNN
- Random Forest
- Extra Trees
- SVM
- MLP

## Evaluation
COmparing models by using KL divergence.
A lower KL score --> better performance.

## Structure of my github repository
- src/: Python model implementations
- notebooks/: Kaggle experiments
- results.csv: Model comparison
